# Vitrum TV Bridge v2 — управление BOXY из ChatGPT

**Статус:** код агента опубликован в приватном репозитории, автоматические тесты проходят. Для управления приставкой агент должен быть запущен **в Termux на твоём телефоне**. Сам по себе GitHub не открывает доступ к Android TV.

**Устройство:** BOXY / 4K Android TV Box, Android 11, ARM32, адрес ADB `192.168.0.160:5555` внутри домашней сети.

## Обновить агент

Если предыдущий `tv_bridge.py --watch` ещё запущен, сначала останови его `Ctrl+C`. Затем выполни:

```bash
git -C ~/vitrum-tv-bridge pull --ff-only
python ~/vitrum-tv-bridge/test_tv_bridge_v2.py
adb -s 192.168.0.160:5555 get-state
```

Ожидаемый результат ADB — `device`.

## Начать управление

```bash
python ~/vitrum-tv-bridge/tv_bridge_v2.py --watch --allow-control
```

После этого ChatGPT сможет **через приватные GitHub Issues**: запускать Vitrum TV, перемещаться по меню кнопками пульта, нажимать OK/Back/Home, запускать другие приложения, останавливать процесс Vitrum TV, получать список приложений и техническую диагностику.

Дополнительные возможности выключены по умолчанию:

- `--allow-screenshots` — скриншоты экрана в приватный репозиторий. **На экране могут быть личные данные. PNG остаётся в истории Git даже после удаления файла.**
- `--allow-installs` — установка локального APK Vitrum TV из `~/storage/downloads` только при совпадении SHA-256. Это не проверка издателя APK, поэтому устанавливай только проверенные сборки.

Для разрешения всех перечисленных возможностей во время сеанса:

```bash
python ~/vitrum-tv-bridge/tv_bridge_v2.py --watch --allow-control --allow-screenshots --allow-installs
```

**Остановка:** `Ctrl+C`. Никогда не открывай порт ADB `5555` в интернет. Не отправляй токен GitHub, приватные ключи ADB и реальные VPN-подписки. GitHub не является защищённым хранилищем VPN-ключей.

## Как работает протокол

Я создаю приватную задачу с точной командой, например:

**Заголовок:** `TVBRIDGE/v2 launch_vitrum`

**Тело:**
```json
{"v":2,"op":"launch_vitrum","args":{}}
```

Локальный агент проверяет владельца GitHub, срок действия запроса (не больше часа), название операции и параметры. Если команда разрешена, передаёт строго ограниченный вызов ADB на приставку и публикует результат в закрытом Issue. Произвольных команд `adb shell`, удаления системных приложений, root-доступа или прошивки через этот мост **нет**.

Первая безопасная проверка после запуска агента — команда `launch_vitrum`, затем `focus_status`, чтобы подтвердить, что окно приложения действительно в фокусе.

Подробная таблица команд и ограничения — в [README.md](README.md).
