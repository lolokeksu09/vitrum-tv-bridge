# BOXY Agent — приложение для Android TV 11

**Статус:** автономный агент на самой приставке BOXY (Skyworth HP44H,
Android TV 11, armeabi-v7a), исходники проекта. Это **отдельное приложение**,
не замена CleanYourTV, Vitrum TV или Android TV Home.

## Задача

После **однократной настройки** работает на приставке без Termux на телефоне:
- сохраняет доступ к приватному GitHub-репозиторию через Android Keystore;
- запускает foreground service с видимым уведомлением, периодически проверяет
  новые команды владельца (раз в 45 секунд);
- возобновляет службу после `BOOT_COMPLETED`, если пользователь её включил;
- умеет `ping`, `home`, `back` и запуск строго четырёх избранных:
  `youtube`, `vkvideo`, `browsehere`, `v2rayng`;
- доступ к Home/Back и запуск приложений требуют **ручного разрешения
  AccessibilityService** через настройки Android TV.

Привилегированное ADB-управление, эмуляция всех кнопок пульта,
скриншоты, удаление приложений, очистка данных, VPN-профили,
обход системных диалогов и беззвучная установка APK **не реализованы**.
Обычное Android-приложение не обладает правами ADB shell/root.
Обновление кода агента требует новой подписанной версии APK и стандартного
подтверждения установки Android. Безопасный протокол не исполняет код из Issues.

## Первая настройка (один раз)

1. Создай **новый PRIVATE** GitHub-репозиторий под учётной записью
   `lolokeksu09` (например, отдельный репозиторий только для контроля ТВ).
   **Публичный `vitrum-tv-bridge` не использовать как командный канал.**
2. Выпусти fine-grained GitHub Personal Access Token с доступом **только**
   к этому приватному репозиторию: `Metadata: read`,
   `Issues: read and write`. Токен не копируй в чат, Issues или исходники.
3. Установи `app-debug.apk` из успешно пройденной сборки GitHub Actions.
   Это **тестовая APK**; её подпись не является постоянной релизной подписью.
4. На BOXY открой **BOXY Agent**, введи имя приватного репозитория и токен,
   нажми «Сохранить и включить».
5. В настройках «Специальные возможности» включи **BOXY Agent**. Служба
   работает только после явного разрешения. Проверь статус на экране агента.
6. Передай в чат **только** отображаемый идентификатор устройства, а также
   имя приватного репозитория. Идентификатор не является ключом доступа.
   Сам токен в чат не отправляй.

APK обновляется через обычную установку Android; владельцу достаточно
провести **первичное** подключение. До завершения первичной настройки
агент не получает команд и не может быть удалённо установлен на ТВ.

## Протокол безопасного управления

В приватном Issues создаётся новый Issue:

**Заголовок:** `BOXYAGENT/v1 ping`

**Тело** (device = идентификатор из приложения):

```json
{"v":1,"op":"ping","device":"<ID-ИЗ-ПРИЛОЖЕНИЯ>"}
```

Операции из ограниченного набора:
`ping`, `home`, `back`, `youtube`, `vkvideo`, `browsehere`,
`v2rayng`. Заголовок `BOXYAGENT/v1 <op>` должен совпадать с `op`.
Все запросы только от GitHub-пользователя `lolokeksu09`, возрастом не
более 3 минут, с точной схемой JSON и правильным ID устройства.
Проверяется `private: true` и владелец контрольного репозитория.
Результат отправляется **только в приватный Issue** и Issue закрывается.

Для исключения повторных нажатий номер команды записывается **перед**
выполнением: после сбоя сети результат может не быть опубликован, но команда
не будет повторно выполнена без новой заявки. Каждая установка запрашивает
разрешение Accessibility отдельно.

## Разработка и CI

Модуль: `boxy-agent/`; Java 17, Android Gradle Plugin 8.7.3,
Gradle 8.9, `minSdk=26`, `targetSdk=30`, без сторонних runtime SDK.

GitHub Actions `BOXY Agent — build test APK`: выполняет
`gradle --no-daemon :app:testDebugUnitTest :app:assembleDebug`,
выкладывает APK в артефакт `boxy-agent-debug-apk`.

Сборка на GitHub Actions **не доказывает** успешный запуск на BOXY;
до установки тесты Android runtime/Accessibility/boot = NOT RUN.
Сохраняй работающий Termux-мост до реального подтверждения готовности
нового агента; не отключай ADB заранее.

## Известные ограничения

- Для установки APK первый раз потребуется стандартное разрешение Android.
- Без Accessibility можно только проверить `ping`.
- OEM может ограничивать автозапуск и уведомления фоновых служб.
- Действие запуска приложения подтверждает передачу Intent, но не гарантирует,
  что сторонняя программа завершила инициализацию.
- Нет права на silent update и доступ к данным других приложений.
- Без приватного control repo и fine-grained токена ничего не выполняется.
