# Scrcpy RU — рабочая документация

**Дата актуализации: 14.11.2026.** Здесь хранится русификация Android-клиента Scrcpy и проектный план следующей версии. Пока это изолированный каталог во временной ветке `build/scrcpy-ru-20261114` приватного `lolokeksu09/vitrum-tv-bridge`, **не отдельный репозиторий**.

## Подтверждённое состояние

- Исходники: [sw3gmach1n3/Scrcpy_for_Android](https://github.com/sw3gmach1n3/Scrcpy_for_Android), коммит `d4a9a8caaaf8f0ff21ca6e3a3a406224b9116dd3`.
- Версия Android-клиента: база `1.5.1-foreground-usb`, в GitHub Actions отдельный пакет `ro.sw3g.scrcpy.ru`.
- Сервер: scrcpy 3.3.4. Более новый официальный scrcpy 5.0.1 не равнозначен совместимому Android-серверу.
- Перевод: 336 строк Android UI и основные разделы справки.
- Проверка: GitHub Actions build `43509360631` завершён успешно. Проверка реальной установки, русских экранов и Wi-Fi ADB на устройстве **не документирована**.
- Профили устройств, новый экран настроек и Android TV D-pad **ещё не реализованы**.

## Цель

Сделать Scrcpy RU удобным менеджером Android-устройств: быстрое подключение по сохранённым профилям, группировка 35 параметров, полноценный ТВ-пульт, предсказуемое переподключение и диагностика — при сохранении текущих USB/TCP ADB и видеопротокола.

## Порядок чтения

1. [ROADMAP](docs/ROADMAP.md) — этапы, задачи и критерии приёмки.

7. [REPOSITORY](docs/REPOSITORY.md) — переход в самостоятельный чистый репозиторий.

**Принцип:** не начинать с полной переписи UI, замены сервера или набора новых зависимостей. Сначала тестируемая модель профилей, затем интерфейс, потом расширения.
