# QA — тест-план и фактическое подтверждение

**Исходные факты (2026-11-14):** workflow run `43509360631` успешно собрал debug APK. Статус device smoke test этой русской версии: **NOT RUN / без подтверждения**. Нельзя утверждать, что реальное устройство проверено.

## Gate A — статический и unit

- Resource parity: все `values`, `values-ro`, `values-ru` имеют полный набор строк; XML парсится.
- Версия upstream pinned; дифф не затрагивает protocol binary в Profiles v1.
- `ProfileValidator`: обязательные поля, порт 1–65535, codecs, числа, enum transport/mode, `extra`.
- `ProfileStore`: round trip/atomic update, damaged input, idempotent migration, activeProfileId, отдельность карт.
- UI navigation: нет пропажи/обнуления расширенных настроек; выбор языка сохраняется.
- Negative path: импорт неизвестной версии не вызывает crash и не выполняет shell/ADB.

## Gate B — APK

- `./gradlew --no-daemon assembleDebug -Pandroid.injected.testOnly=false`.
- `aapt dump badging`: `ro.sw3g.scrcpy.ru`, поддерживаемая версия Android; SHA-256 и build run id в отчёте.
- `apksigner verify --verbose` и подписант зафиксированы; debug APK не выдаётся за релизную подпись.
- Сборка без изменения исходного commit и без непроверенных бинарников.

## Gate C — реальное устройство

| Сценарий | Действие | Критерий |
| --- | --- | --- |
| Wi-Fi ADB | выбрать профиль TV, подключиться к авторизованной Android TV Box | изображение видно, Back/Home/D-pad работают |
| Отказ в ADB | убрать авторизацию и подключить | ясный запрос/ошибка, без бесконечной тишины |
| Неверный IP/порт | выбрать несуществующий endpoint | ошибка сети показана, UI не блокируется |
| USB OTG | проводное соединение двух Android, дать разрешение | видео/управление работают, detach завершает сеанс |
| 2 профиля | изменять quality/host между подключениями | значения не протекают между устройствами |
| Перезапуск | закрыть/открыть приложение | имена, настройки, выбранный профиль сохранены |
| Активный Session | редактировать профиль без явного переподключения | текущая сессия стабильна |
| Media | MP4 H264 и screenshot, экспорт | файл открывается, нет повреждения |
| Языки | ru/en/ro, основные и advanced экраны | читаемый перевод, нет обрезки критичных кнопок |
| Сбой/повтор | disconnect вручную, потерять Wi-Fi, вернуться | нет автоподключения после manual stop; bounded retry |

## Рекомендуемая матрица

Контроллер: реальный Android-телефон. Цель A: Android 11 TV Box (ранее известная аппаратная база). Цель B: второй Android при наличии. USB не заменяется только сетевым тестом. Проверить переключение ориентации и жестов.

## Evidence

Для каждого сценария: commit SHA, APK SHA-256, модель/API цели, способ подключения, наблюдение, PASS/FAIL/NOT RUN и краткий лог без IP, токенов и личных данных. Сборка != установка; установка != рабочий поток; скриншот исходного старого приложения != снимок новой ревизии.
