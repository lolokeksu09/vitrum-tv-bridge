# UX — экраны и взаимодействия

Статус: дизайн-спецификация, без утверждения о готовом UI. Тема: AMOLED/near-black, типографическая иерархия, доступные зоны нажатия, без лишних линий, декоративных градиентов и случайных иконок.

## Главная / Мои устройства

- Вверху: «Scrcpy RU», текущий статус подключения; заметная кнопка добавления профиля.
- Карточка: название (например, «Android TV»), транспорт, host:port **только у TCP**, качество видео, режим управления, последнее известное состояние.
- Главный CTA: «Подключить». Вторичные: изменить, копировать, переименовать, удалить с подтверждением.
- При отсутствии профилей: один путь «Создать профиль»; миграция существующих настроек без диалога-перезаписи.
- Нет фиктивного «Онлайн» без активной проверки. Последнее успешное подключение не означает текущую доступность.

## Экран редактирования профиля

Поля имени, TCP/USB, адреса/порта, тип использования (обычное Android / Android TV) и качество. Основное: максимальный размер кадра, FPS, битрейт, codec, audio, режим управления, автопереподключение. «Расширенные» раскрывают все остальные параметры (не удаляются, не сбрасываются при скрытии).

Кнопка «Применить» сохраняет **после** validation; ошибку показывать рядом с полем. Пресеты «Качество», «Сбалансированный», «Экономия» должны явно показывать, какие 4 параметра изменят.

## Экран сессии

Видео занимает доступную область с корректным letterbox и управляемым масштабом. `•••` открывает настройки конкретной сессии, не редактируя профиль скрытно. Отдельная кнопка «ТВ-пульт» у профилей типа Android TV.

## ТВ-пульт

D-pad: `KEYCODE_DPAD_UP/DOWN/LEFT/RIGHT`, `KEYCODE_DPAD_CENTER`; системные `KEYCODE_BACK`, `KEYCODE_HOME` и громкость. Отправка через уже существующий `Control.clickKey`, только если контроль доступен. Не имитировать стрелки жестами. Альбомная ориентация — настройка **локального телефона**, не `capture_orientation` на управляемой приставке. При потере соединения кнопки не должны изображать успешное выполнение.

## Состояния / ошибки

`idle`, `connecting`, `adb-auth-required`, `starting-server`, `waiting-for-video`, `connected`, `reconnecting`, `error`, `disconnected`. Время и состав фаз должны соответствовать реальным событиям `Session`, а не искусственным таймерам. Сообщение об ошибке включает конкретный этап и действие пользователя.

## Accessibility / i18n

Минимально разумные targets (от 48 dp), читаемые размеры шрифта, контрастные состояния, contentDescription для иконок, отсутствие ссылок только цветом; значения кнопок «Home», «OK», кодеков и команд не путать с переводом wire protocol. Русский/английский/румынский не должны переполнять карточки. Проверить портретный и альбомный режимы.
