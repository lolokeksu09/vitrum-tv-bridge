## Phase 1 — Profiles v1 (P0, первый реализуемый функционал)

1. Написать `Profile` / `ProfileStore` с версионированным форматом и атомарной записью.
2. Реализовать валидацию и idempotent миграцию 35 полей + адреса/порта из текущего `settings`.
3. Реализовать CRUD, выбор активного профиля и копирование настроек.
4. Подключить `Options` к снимку активного профиля; изменить только wiring, не формат команд scrcpy.
5. Добавить минимальные проверки миграции, rollback при ошибке и регрессии существующих функций.
6. Применять изменение профиля к **следующему** сеансу; активную сессию не менять молча.

**Gate:** 2 профиля с различными host/port/quality переключаются без смешивания настроек; после перезапуска значения сохраняются; уже существующее соединение и ADB key не затронуты.

## Phase 2 — UI/UX, упрощение 35 опций (P0/P1)

1. Домашний экран «Мои устройства» и действие «Подключить».
2. Группы: основные, управление, запись/медиа, расширенные.
3. Быстрые пресеты качества как шаблон **профиля**, а не скрытое изменение глобальных prefs.
4. Описание и зависимость опций (например, запись MP4 требует H.264 и AAC при включённом звуке).
5. Отделить системные настройки приложения: язык, автоподключение USB, журнал.

**Gate:** пользователь подключается к сохранённому устройству без посещения 35 карточек; доступ ко всем прежним опциям сохранён.

## Phase 3 — Android TV и надёжность (P1)

1. D-pad (UP/DOWN/LEFT/RIGHT/OK/BACK/HOME), громкость, адаптация под альбомную ориентацию.
2. Состояния соединения: проверка адреса → ADB → авторизация → сервер → видео.
3. Повторные попытки с ограничением и backoff; кнопка «Отменить».
4. Ротация журналов; явный экспорт только по действию пользователя.

**Gate:** навигация по Android TV реализуется без сенсорных эмуляций; ручное отключение не инициирует повторного подключения; сбой отображается в правильной фазе.

## Phase 4 — расширения (P2, после device QA)

- Импорт/экспорт профилей с валидацией и без ADB-ключей, pairing-кодов, логов.
- История собственных скриншотов/MP4 и управление экспортом.
- Диагностика FPS, битрейта и обрывов только на основе реально измеряемых величин.
- Исследование переноса протокола с scrcpy server 3.3.4 на актуальную ветку 5.x **отдельной задачей**, с проверкой handshake, audio, video, control и MediaCodec.
