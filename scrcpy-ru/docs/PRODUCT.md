# PRODUCT — область и принятые решения

Актуально: 2026-11-14. Статус: проектное решение; функции будущей версии пока не реализованы.

## Для кого

- Управление Android TV / TV Box с телефона по локальной сети.
- Просмотр и управление вторым Android по Wi-Fi ADB или прямому USB.
- Разработчики и технические пользователи, которым нужны Codec, bitrate, FPS, shell и диагностика.

## Главная пользовательская задача

Открыть приложение, выбрать устройство, увидеть понятный статус и нажать «Подключить», не перенастраивая десятки параметров при каждом переключении.

## Есть сейчас (подтверждено исходниками)

USB host/OTG, TCP ADB, беспроводное спаривание, поток видео, опциональный звук, 3 режима управления, скриншоты и MP4, консоль, shell, 3 пресета видеокачества. `Options.fields()` содержит **35** опций. Общие параметры хранятся в `SharedPreferences("settings")`. Три пресета изменяют только `max_size`, `max_fps`, `video_bit_rate`, `video_codec`.

## Цель первой функциональной версии (Profiles v1)

1. Хранение нескольких устройств с именами, видом транспорта и полным набором настроек сеанса.
2. Создание, выбор, копирование, переименование, удаление и редактирование профиля.
3. Безопасная однократная миграция текущих параметров без потери ADB-ключа.
4. Домашняя страница с активным профилем и быстрым подключением.
5. Основные/расширенные настройки по смысловым группам.
6. Android TV D-pad только после стабилизации профилей.

## Вне первого этапа

Нет фонового сканирования LAN, доступа к интернету для удалённого управления, учётных записей, облачной синхронизации, хранения парных кодов, автоматической выдачи ADB разрешений, root, безусловного обновления сервера, произвольной автоматизации shell.

## Принципы

- Технические параметры и официальные ADB команды не переводить/не переименовывать в протоколе.
- Не менять существующее поведение сети и USB ради дизайна.
- Никакой скрытой телеметрии. Логи и скриншоты остаются локально, пока пользователь сам не экспортирует.
- Не выдавать успешную сборку APK за проверенный запуск на устройстве.
